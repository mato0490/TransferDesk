# Instructions de maintenance du dépôt

## Documentation obligatoire

Après chaque modification du projet, vérifier la documentation avant de terminer :

1. mettre à jour `README.md` si l'installation, l'utilisation, l'architecture,
   la configuration, les commandes ou le comportement ont changé ;
2. mettre à jour le document spécialisé concerné (`BUILD-MACOS.md` ou
   `MIGRATION-QT.md`) lorsqu'il est touché ;
3. ajouter dans `CHANGELOG.md`, sous `Non publié`, toute modification visible par
   l'utilisateur, correction notable ou évolution technique importante ;
4. actualiser la date indiquée dans `README.md` si son contenu est modifié ;
5. ne jamais déclarer une tâche terminée sans avoir vérifié si sa documentation
   doit évoluer.

La documentation et le code correspondant doivent faire partie du même changement.
